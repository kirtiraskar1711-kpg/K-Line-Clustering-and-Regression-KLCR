# K-Line Clustering and Regression (K-LCR)

This upload contains the research code, selected data files, analysis outputs, and figures prepared for the study of K-LCR for bivariate pattern recognition.

**Status:** Research materials are being organized and checked. Do not treat this repository snapshot as a final, independently validated release.

## Contents
- `01_Algorithm/`: K-LCR and comparator implementations.
- `02_Simulation_Data/`: simulation-generation and replicate-analysis scripts.
- `03_Real_Datasets/`: selected empirical datasets and provenance notes.
- `04_Experiments/`: comparative and sensitivity analysis scripts.
- `05_Results/`: CSV outputs, figures, and workbooks.
- `06_Documentation/`: methodological and reproducibility notes.

## Scope
The current study concerns bivariate pattern recognition. Prediction is outside the scope of this study and is reserved for future research.

## Important data note
The Fuel dataset is intentionally not included in this initial public upload because its provenance and redistribution conditions require verification. The hypothetical dataset is illustrative. Empirical dataset sources and preprocessing should be checked against the final manuscript before a formal release.
