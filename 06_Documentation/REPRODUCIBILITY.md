# Reproducibility notes

This is an initial research snapshot, not yet a formal archival release.

Before relying on these outputs, record and verify:
1. Python version and package versions.
2. Exact command used to run each script.
3. Random seeds and replicate counts.
4. Data source, version, license, and preprocessing for each empirical dataset.
5. Initialization, tie-breaking, empty/small-cluster handling, convergence, and cycle-handling rules.
6. Agreement between regenerated results and the manuscript tables/figures.

The Fuel dataset is excluded pending provenance verification. Predictive performance is not evaluated in this study.
